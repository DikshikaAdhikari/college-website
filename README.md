# 🎓 College Website

A modern and responsive **College Website** built using **HTML and CSS**. This project presents a clean and user-friendly interface for showcasing college information, campus facilities, leadership, students, and other important institutional details.

## 🌐 Overview

The **College Website** is a frontend web development project designed to provide visitors with an attractive and organized way to explore a college's information.

The project focuses on:

* 🎨 Clean and simple UI design
* 📱 Responsive website layout
* 🏫 College and campus information
* 📚 Library and academic resources
* 👨‍🎓 Student information
* 👨‍🏫 Principal/leadership section
* 🖼️ Visual presentation using campus and institutional images

## ✨ Features

* 🏠 **Home Page** — Introduction and overview of the college
* 🏫 **Campus Section** — Highlights the college campus
* 📚 **Library Section** — Showcases library facilities
* 👨‍🏫 **Principal Section** — Displays information about college leadership
* 👨‍🎓 **Students Section** — Represents the student community
* 🎨 **Custom Styling** — Designed using a dedicated CSS stylesheet
* 📱 **Responsive Layout** — Structured for a better experience across screen sizes

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/DikshikaAdhikari/college-website.git
```

### 2. Navigate to the Project

```bash
cd college-website
```

### 3. Run the Website

Simply open:

```text
index.html
```

in your preferred web browser.

No backend server or additional dependencies are required.
